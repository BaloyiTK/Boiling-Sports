# Forme — Beauty Storefront

Responsive React + Vite beauty and skincare storefront. Catalogue and product details are static frontend data in `src/data/products.js`; product imagery uses fixed image URLs. No backend, API, database, authentication or payment integration is configured.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

Includes responsive storefront, category navigation, search, price and sale filters, sorting, saved-product hearts, shopping bag with quantity controls and subtotal, and a demo free-delivery progress indicator. Checkout is intentionally non-functional and does not collect payment. Replace the sample brand, product data and image URLs with approved store content.
